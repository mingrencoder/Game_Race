# 跑跑赛车 (Neon Racing) - 基础架构与权限系统 PRD (Document B)

## 1. 架构总述
本模块旨在为《跑跑赛车》提供脱离传统重型数据库（如 MySQL/MongoDB）的轻量化 Node.js 后端基建。核心目标是实现“账号自动分配”、“高强度加密防篡改落盘”以及“细粒度的 GM 动态管控”。系统必须具备极高的本地运行兼容性与线上部署安全性。

---

## 2. 账号与鉴权体系 (Account & Auth)

### 2.1 8位数字账号分配机制
摒弃传统的用户自定义账号，统一采用系统分配制以规范数据标准。
*   **注册机制 (Registration)**：
    *   客户端请求注册时，仅提供 `nickname` (车手昵称) 和 `password` (密码)。
    *   后端校验密码长度必须为 **6 到 16 位字符**。
    *   后端自动生成一个唯一的 **8 位纯数字账号 (Account ID)**，起始值为 `10000000` 并保证自增防重。
    *   密码必须使用 `Bcrypt` 算法进行不可逆哈希处理后落盘，绝不允许明文存储。
*   **登录机制 (Login)**：
    *   玩家使用 `8位数字账号` + `密码` 登录。
    *   密码校验通过后，服务器签发加密身份 Token（建议使用 JWT），内含玩家的 `UID` 与权限 `Role`，供后续接口无感重连。

### 2.2 特权与管理员机制
*   **系统级注入**：在服务端应用启动时，系统需自检是否存在管理员。若无，自动注入超级管理员账号：账号 `admin`，密码 `pop1993`，并打上 `role: 'admin'` 标签。
*   **权限拦截**：针对普通资产接口，仅需校验有效 JWT；针对 GM 接口，需额外校验 `role === 'admin'`。

### 2.3 个人中心模块 (Personal Center API)
*   **资料展示**：下发不可修改的 8位数字账号及注册时间戳。
*   **修改昵称**：接收新昵称，后端需执行 O(1) 的全局防重校验，确保全服唯一。
*   **修改密码**：接收 `oldPassword` 和 `newPassword`。使用 Bcrypt 验证旧密码后，对新密码进行哈希覆盖。

## 3. 云端存储与加密安全架构 (Storage & Security)

为了实现轻量化且绝对安全的落盘，文件结构需进行严格的“索引与资产分离”。

### 3.1 全局索引库 (`accounts_index.json`)
*   **定位**：系统的大脑地图，不包含任何游戏资产。
*   **数据结构要求**：以 `AccountID` 或 `Nickname` 为键，实现 O(1) 的极速查重与登录寻址。
*   **存储内容**：`Account ID`, `Nickname`, `Bcrypt Password Hash`, `UID (指向具体的资产文件)`。

### 3.2 加密资产库 (`UID_xxx.json`)
*   **定位**：玩家的个人金库，每一个注册玩家对应一个独立文件。
*   **内容划分**：包含 `wallet` (金币)、`garage` (车辆、耐久度、强化等级)、`inventory` (材料道具)。
*   **AES-256-GCM 强制加密**：
    *   内存中以明文 JSON 交互，但落盘写入磁盘前，必须经过原生的 `crypto` 模块使用 AES-256-GCM 算法进行加密。
    *   密文结构必须包含：`IV (初始向量)` + `AuthTag (认证标签)` + `Ciphertext (加密数据)`。
    *   读取时若 `AuthTag` 校验失败（意味着文件被玩家或黑客使用编辑器强行篡改），直接抛出异常并拦截。

### 3.3 I/O 安全防护 (Debounce/Queue)
防止玩家高频操作（如连续强化赛车）导致 Node.js 读写同一 JSON 文件时发生死锁或文件损坏。存储层必须实现写入队列或防抖（Debounce）机制。

## 4. 前端 GM 控制台接口 (Game Master API)

所有 `/api/gm/*` 路由必须经过严格的 admin 鉴权。

### 4.1 全局动态数值调控中心 (Game Data Configurator)
将硬编码（Hardcode）的数值抽离为系统配置文件（如 `game_config.json`）。GM 可通过 API 覆写并在内存中热更新以下参数：
*   **赛车参数**：各梯队赛车的 30天售价/永久售价、初始五维属性、耐久掉落率、满血保养费、+1至+5满级的各阶段成长增量。
*   **经济杠杆**：AI难度乘数、人数乘数、单人/组队杯赛大奖基础值。
*   **物价调控**：T1-T3配件售价与属性、各级涂装售价、强化材料单价。

### 4.2 玩家全资产强改中心 (Player Data Override)
*   **精确定位**：通过 8位数字账号或昵称查询玩家的加密资产库并解密展示。
*   **钱包与背包强改**：直接覆写金币余额（Wallet）和强化核心/保护卡数量（Inventory）。
*   **车库上帝模式 (Garage Override)**：
    *   发放新车 / 强制没收指定车辆。
    *   **一键满改**：将指定车辆强化等级强制设为 `level: 5`，耐久度重置为 `100`。
    *   **顶级配件装配**：直接修改车辆的 `equippedParts` 对象，一键为其装配全套 T3 顶级组件（如 V3反物质引擎、量子锚定轮胎等）。
